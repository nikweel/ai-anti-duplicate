**Photo Duplicate Finder AI** — безкоштовна програма з відкритим кодом для пошуку дублікатів **фотографій** (JPG, PNG, WebP + RAW) за **вмістом кадру**, а не за розміром, датою чи хешем. Працює на ШІ, тому впізнає той самий знімок, навіть якщо його зменшено, перестиснуто, трохи обрізано чи повернуто. Призначена лише для колекцій фото, а не для документів, відео чи інших файлів.

> 🛡️ **Безпечно:** програма лише *копіює* файли. Вона ніколи не видаляє, не переміщує й не змінює ваші оригінали.

## Як користуватися
1. Оберіть папку з фотографіями (усі вкладені папки включено).
2. Оберіть папку, куди зберегти унікальні фото.
3. Оберіть правило для дублікатів: найновіший, найбільший файл, найвища роздільна здатність або вручну для кожної групи.
4. Натисніть «Знайти дублікати та зберегти». Фото без дублікатів копіюються як є, а з кожної групи дублікатів — лише обрані вами.

## Завантаження (встановлювати Python не потрібно)
Завантажте файл для своєї системи зі сторінки [Releases](https://github.com/nikweel/photo-duplicate-finder-ai/releases/latest):

| Система | Файл | Як запустити |
|---|---|---|
| **Windows** | `…-Setup.exe` | Подвійний клік і далі за вказівками встановлювача. |
| **Linux** | `….AppImage` / `….deb` | AppImage: правий клік → Властивості → дозволити виконання як програми, потім подвійний клік; або `.deb`: подвійний клік → Встановити. |
| **macOS** | `….dmg` | Відкрийте `.dmg` і перетягніть програму в «Програми». |

Під час першого запуску оберіть модель розпізнавання в налаштуваннях, і програма завантажить її один раз (потрібен інтернет). Далі вона працює повністю офлайн.

## Попередження системи під час першого запуску (це нормально)
Програма безкоштовна й не підписана сертифікатом (вони платні), тому система може попереджати. Код відкритий, а завантажене можна перевірити за `SHA256SUMS.txt` із релізу.

- **Windows:** «Windows захистила ваш ПК» → **Докладніше → Усе одно виконати**.
- **macOS:** відкрийте **Системні налаштування → Конфіденційність і безпека**, прокрутіть униз і натисніть **Усе одно відкрити** біля програми.
- **Linux:** попереджень немає.

## Можливості
- Порівняння вмісту фото за допомогою ШІ (поворот, зменшення, перестиснення не заважають)
- Три моделі: легка, середня й важка; прискорення відеокартою
- Ручна перевірка: позначайте кілька фото для збереження, наведіть курсор, щоб збільшити
- Імена в папці призначення: вихідні або за датою (EXIF, мітка часу), без перезапису
- Усі вкладені папки
- 30 мов, темна й світла тема
